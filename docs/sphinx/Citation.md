# Citing Cholla

If you use Cholla for your research, please cite the original method paper, [Schneider & Robertson (2015, ApJS)](https://ui.adsabs.harvard.edu/abs/2015ApJS..217...24S/abstract).
Additionally, please cite

* the cosmology paper, [Villasenor et al. (2021, ApJ)](https://ui.adsabs.harvard.edu/abs/2021ApJ...912..138V/abstract) if you use self-gravity or cosmology.
* the MHD paper, [Caddy & Schneider (2024, ApJ)](https://ui.adsabs.harvard.edu/abs/2024ApJ...970...44C/abstract), if you use MHD

Copies of the BibTeX entries are provided below:
